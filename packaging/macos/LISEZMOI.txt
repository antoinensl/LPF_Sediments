SEDIMENTS - macOS (Apple Silicon : M1, M2, M3, M4...)
=====================================================

Installation
------------
1. Ferme Reaper.
2. Clic droit (ou Ctrl + clic) sur « Installer.command », puis « Ouvrir ».
   macOS demande une confirmation la première fois, car le plugin
   n'est pas signé par Apple : clique sur « Ouvrir ».
   Si macOS refuse quand même : Réglages Système > Confidentialité et
   sécurité, en bas, « Ouvrir quand même ».
3. Rouvre Reaper : Sediments apparaît dans la liste des FX
   (en VST3 et en AU).

Le plugin s'installe pour ton compte uniquement :
  ~/Library/Audio/Plug-Ins/VST3/Sediments.vst3
  ~/Library/Audio/Plug-Ins/Components/Sediments.component
et l'application autonome dans /Applications.

Rien d'autre à installer : libtorch est inclus dans le plugin.

Code source et mode d'emploi : https://github.com/antoinensl/LPF_Sediments
