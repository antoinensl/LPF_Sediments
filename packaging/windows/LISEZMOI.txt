SEDIMENTS - Windows
===================

Installation
------------
1. Ferme Reaper.
2. Double-clique sur INSTALLER.bat.
   Si Windows affiche « Windows a protégé votre ordinateur » :
   « Informations complémentaires », puis « Exécuter quand même ».
3. Rouvre Reaper. La première fois seulement :
   Options > Preferences > Plug-ins > VST, ajoute le dossier indiqué
   par l'installateur, clique sur Re-scan, puis OK.
4. Sur une piste : FX > cherche « Sediments ».

Mise à jour : ferme Reaper et relance INSTALLER.bat.

Rien d'autre à installer : le plugin et libtorch sont dans ce dossier.
Il te faut seulement un modèle RAVE (.ts) si tu veux jouer avec un
modèle ; sans modèle, le plugin joue tes sons d'origine.

Code source et mode d'emploi : https://github.com/antoinensl/LPF_Sediments
