SEDIMENTS - Windows
===================

Installation
------------
1. Close Reaper.
2. Double-click INSTALL.bat.
   If Windows shows "Windows protected your PC":
   click "More info", then "Run anyway".
3. Reopen Reaper. First time only:
   Options > Preferences > Plug-ins > VST, add the folder shown
   by the installer, click Re-scan, then OK.
4. On a track: FX > search for "Sediments".

To update: close Reaper and run INSTALL.bat again.

Nothing else to install: the plugin and libtorch are in this folder.
You only need a RAVE model (.ts) if you want to play with a model;
without one, the plugin plays your original sounds.

Source code and user guide: https://github.com/antoinensl/LPF_Sediments
